## Philosophy

- Roll your own stack: pick only what you need, nothing extra.
- Minimal templates: bare-bones scaffolds with zero bloat.
- Latest dependencies: always current and stable by default.
- Idiomatic per language: a generated Python project should look like a Python developer wrote it — and a Go or Rust one should look like a Go or Rust developer wrote it.
- Free and open source: forever.

## Languages

TriStack scaffolds backend projects in multiple languages. Each has its own option set (framework, ORM, migrations, package manager, addons) in the [Compatibility reference](/docs/cli/compatibility).

| Language | Status      |
| -------- | ----------- |
| Python   | Scaffolding |
| Go       | Scaffolding |
| Rust     | Scaffolding |

The CLI ships as a standalone native binary. The invoker differs per language:

| Language | Run the CLI                   |
| -------- | ----------------------------- |
| Python   | `uvx tristack` (PyPI wrapper) |
| Go       | `tristack` (curl installer)   |
| Rust     | `tristack` (curl installer)   |

## Get Started

### Prerequisites

You only need the runtime of whatever language you scaffold, plus **Git** (optional, [git-scm.com](https://git-scm.com/)) to initialize a repository:

| Language | Runtime                                              | Package manager                                                         |
| -------- | ---------------------------------------------------- | ----------------------------------------------------------------------- |
| Python   | Python 3.12+ ([python.org](https://www.python.org/)) | `uv` ([astral.sh/uv](https://docs.astral.sh/uv/)) — or `poetry` / `pip` |
| Go       | Go 1.22+ ([go.dev](https://go.dev/dl/))              | `go`                                                                    |
| Rust     | Rust 1.75+ ([rustup](https://rustup.rs/))            | `cargo`                                                                 |

To run the CLI itself install it once (`pipx install tristack` / `uv tool install tristack`) or run it on demand with `uvx tristack` (Python path). Go and Rust devs run the standalone `tristack` binary from the curl installers.

### CLI (prompts)

```bash
uvx tristack
```

Follow the interactive prompts to pick your language, framework, ORM/migrations, database, package manager, and addons.

Skip prompts and use the default stack:

```bash
uvx tristack --yes
```

### Stack Builder (UI)

- Visit [/new](/new) to pick your stack, preview the generated file tree live, and copy the exact CLI command. The builder supports Python, Go, and Rust stacks.
- The command you copy runs verbatim:

```bash
uvx tristack my-tristack-app \
  --language python \
  --framework fastapi \
  --orm sqlmodel \
  --migrations alembic \
  --database sqlite \
  --package-manager uv \
  --addons docker ruff pytest \
  --install
```

### AI agent (JSON-first)

Let an LLM CLI or CI job scaffold projects for you with the fully JSON-first `create-json` command — no prompts, one machine-readable payload. See [Agent Workflows](/docs/cli/agent-workflows).

A native agent plugin (Claude Code / Codex MCP) ships in a later phase.

## Common Setups — Python

The examples below use the Python runner (`uvx tristack`).

### Default Stack

```bash
uvx tristack my-api \
  --language python \
  --framework fastapi \
  --orm sqlmodel \
  --migrations alembic \
  --database sqlite \
  --package-manager uv \
  --addons docker ruff pytest
```

### Postgres API

```bash
uvx tristack my-api \
  --language python \
  --framework fastapi \
  --orm sqlalchemy \
  --migrations alembic \
  --database postgres \
  --package-manager uv \
  --addons docker pytest
```

### Django Monolith

```bash
uvx tristack my-django \
  --language python \
  --framework django \
  --database postgres \
  --package-manager poetry \
  --addons docker ruff mypy pytest
```

### Minimal Flask Service

```bash
uvx tristack my-micro \
  --language python \
  --framework flask \
  --database none \
  --package-manager uv \
  --addons pytest
```

## Common Setups — Go

The Go CLI runs as the standalone `tristack` binary.

### Gin + GORM + SQLite

```bash
tristack my-api \
  --language go \
  --framework gin \
  --orm gorm \
  --migrations goose \
  --database sqlite \
  --package-manager go \
  --addons docker air golangci-lint
```

### Fiber + sqlx + Postgres

```bash
tristack my-api \
  --language go \
  --framework fiber \
  --orm sqlx \
  --migrations golang-migrate \
  --database postgres \
  --package-manager go \
  --addons docker air golangci-lint
```

## Common Setups — Rust

The Rust CLI runs as the standalone `tristack` binary.

### Axum + SeaORM + SQLite

```bash
tristack my-api \
  --language rust \
  --framework axum \
  --orm seaorm \
  --migrations none \
  --database sqlite \
  --package-manager cargo \
  --addons docker cargo-watch clippy
```

### Actix Web + Diesel + Postgres

```bash
tristack my-api \
  --language rust \
  --framework actix-web \
  --orm diesel \
  --migrations none \
  --database postgres \
  --package-manager cargo \
  --addons docker cargo-watch clippy
```

## Flags Cheat Sheet

See the full list in the [CLI Reference](/docs/cli). Option sets are per language:

- `--language`: python, go, rust
- `--framework` (python): fastapi, litestar, django, flask
- `--framework` (go): gin, fiber, echo, chi, stdlib
- `--framework` (rust): axum, actix-web, rocket, warp, salvo, loco
- `--orm` (python): sqlmodel, sqlalchemy, tortoise, none
- `--orm` (go): sqlc, gorm, sqlx, none
- `--orm` (rust): seaorm, diesel, sqlx-rust, none
- `--migrations` (python): alembic, none
- `--migrations` (go): goose, golang-migrate, none
- `--migrations` (rust): none
- `--database`: sqlite, postgres, mysql, none
- `--package-manager` (python): uv, poetry, pip
- `--package-manager` (go): go
- `--package-manager` (rust): cargo
- `--addons` (python): docker, ruff, mypy, pytest, github-actions, fumadocs, starlight, none
- `--addons` (go): docker, air, golangci-lint, github-actions, fumadocs, starlight, none
- `--addons` (rust): docker, cargo-watch, clippy, github-actions, fumadocs, starlight, none
