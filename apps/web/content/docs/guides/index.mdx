## Install the CLI

Install the standalone binary for your OS, or run on demand with `uvx tristack` over Python:

<Tabs items={["Windows", "macOS", "Linux", "Python (any OS)"]} defaultIndex={0}>
  <Tab value="Windows">
    ```powershell
    irm https://tristack.space/install.ps1 | iex
    ```
  </Tab>

  <Tab value="macOS">
    ```bash
    curl -fsSL https://tristack.space/install.sh | bash
    ```
  </Tab>

  <Tab value="Linux">
    ```bash
    curl -fsSL https://tristack.space/install.sh | bash
    ```
  </Tab>

  <Tab value="Python (any OS)">
    ```bash
    uvx tristack
    ```
  </Tab>
</Tabs>
